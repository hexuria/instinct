# HDC capacity (measured)

Generated by `cargo run --release -p pua-hdc --example capacity`; do not edit by hand.

Each cell: **decode recall / sign recall** when `k` distinct codebook entries (of `n`)
are bundled with weight 1, over 10 deterministic trials. *Decode* is the iterative
top-k of `Codebook::decode` (reads the integer accumulator and subtracts each found
member; floor = −1000). *Sign* is one-shot top-k by similarity to the thresholded
bundle, the textbook capacity measure, shown for contrast: it is why spec §4.5 says
to decode from the accumulator.

Capacity is measured, not assumed (spec §4.5). Use the table to pick `D` for a
consumer's codebook size and expected bundle size; a cell below 100% means decode can
return a non-member, so consumers must keep the profile's similarity floor and margin
checks in front of any HDC answer.
